One local binary captures four signals, scrubs secrets, and replays anywhere

Developers will not adopt a session recorder if it slows down their terminal or risks leaking API keys. DevTape must run strictly on-device with zero cloud dependency by default. A lightweight background daemon attaches to four passive event streams—shell PTY output, shadow git tree snapshots, a local loopback HTTP/gRPC proxy, and Model Context Protocol (MCP) tool-call logs—then passes every event through an in-memory secret redactor before writing to a content-addressed SQLite and Zstd archive.

Once captured, a single .tape artifact powers three high-value workflows: instant local workspace rewind (devtape rewind -5m) when an experiment or AI agent goes sideways, one-command sanitized sharing for GitHub issues, and structured MCP replay so any coding agent can inspect the exact failing trace instead of guessing from pasted logs.

Engineering choices that maximize speed, trust, and contributor velocity

Open-source projects die when installation takes ten minutes or contributors cannot compile the codebase locally. Every technology choice below optimizes for single-binary distribution, sub-millisecond overhead, and easy community pull requests.

Core Daemon in Rust

Compile to one self-contained binary distributed via Homebrew, Cargo, Scoop, and curl | sh. Use pseudo-terminal (PTY) wrapping for shell capture, git write-tree for instant non-destructive file snapshots, and SQLite with Zstd compression so an hour of coding compresses to under 5 MB.

Zero-Trust Secret Scrubbing

Run deterministic regex rules plus Shannon entropy scanning before any byte touches disk. Automatically mask AWS keys, JWTs, .env secrets, Bearer tokens, and database URLs with reversible local placeholders, and require an explicit preview diff before exporting a shareable .tape.

Local Replay UI & MCP Server

Bundle a static React + TypeScript timeline scrubber directly into the binary so devtape view opens instantly at localhost with zero Node runtime required. Expose a built-in MCP server so Claude Code, Cursor, Codex, and open-source agents can query failing steps directly.

Engineer virality into the artifact, not just the marketing

Great code alone rarely crosses 5,000 stars. Repositories that reach 100K+ stars—and build a 1M+ combined follower ecosystem across GitHub, X, YouTube, and Discord—make sharing effortless and rewarding.

  • The 15-second README hook: Open your repository with a crisp, high-contrast terminal GIF showing an AI coding agent breaking a test suite, a single devtape rewind restoring the workspace in 1 second, and a one-line command exporting a clean bug report.
  • Zero-install web viewer for .tape files: Host a static client-side viewer (WebAssembly) where anyone clicking a shared .tape link in a GitHub Issue can scrub the bug timeline in their browser—with a subtle "Recorded with DevTape" badge linking straight back to your repo.
  • Companion curated hub: Launch a sibling folder or linked repo of community-contributed redaction rules, MCP agent adapters, and debugging playbooks. Curated plugins invite low-friction pull requests, turning passive users into invested contributors.
  • Build-in-public distribution: Publish weekly 60-second engineering demos on X, YouTube Shorts, and LinkedIn showing real bugs solved with DevTape. Coordinate your Week 16 v1.0 release with Show HN, r/programming, Dev.to, and AI-developer newsletters.
